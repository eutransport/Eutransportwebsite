# Assets — Logo & Favicon

Plaats hier je merkbestanden. De website verwijst automatisch naar de bestandsnamen hieronder.

## Verwachte bestanden

| Bestand              | Doel                                     | Aanbevolen formaat            |
|----------------------|------------------------------------------|-------------------------------|
| `logo.svg`           | Hoofdlogo in header & footer             | SVG (schaalbaar, wit/licht)   |
| `logo-dark.svg`      | (optioneel) Donkere variant              | SVG                           |
| `favicon.svg`        | Modern favicon (browser tab)             | SVG, vierkant                 |
| `favicon.ico`        | Fallback voor oudere browsers            | 32×32 of multi-size ICO       |
| `apple-touch-icon.png` | iOS home-screen icoon                  | 180×180 PNG                   |

## Tips

- Lever het logo bij voorkeur als **SVG** met transparante achtergrond, in een lichte/witte kleur — de header staat op een donkere background.
- Voor het favicon werkt een simplistische versie van je merkteken het best (herkenbaar op 16×16 px).
- Zolang deze bestanden ontbreken toont de site een tekstueel logo ("E&U TRANSPORT") als fallback — geen broken images.
